\# Windows Event Log Analysis



\## Project Overview



This project demonstrates basic Security Operations Center (SOC) log analysis using Windows Event Viewer.



\## Objectives



\- Explore Windows Security Logs

\- Investigate login activity

\- Analyze authentication events

\- Document findings



\## Tools Used



\- Windows 11

\- Event Viewer



\## Events Investigated



| Event ID | Description |

|-----------|-------------|

| 4624 | Successful Login |

| 4625 | Failed Login |

| 4634 | Logoff |

| 4672 | Administrative Login |
